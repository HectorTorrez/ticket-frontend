# Sections

This file defines all sections, their ordering, impact levels, and descriptions.
The section ID (in parentheses) is the filename prefix used to group rules.

---

## 1. Fundamentals (fundamentals)

**Impact:** CRITICAL  
**Description:** Core principles that govern every UI decision: logic over opinion, consistency, hierarchy, and reducing cognitive load.

## 2. Less Is More (simplicity)

**Impact:** HIGH  
**Description:** Simplify interfaces by removing unnecessary styles, avoiding hidden critical content, and distinguishing minimal from simple.

## 3. Colour (color)

**Impact:** HIGH  
**Description:** Use colour sparingly and purposefully. Meet WCAG contrast requirements and never rely on colour alone.

## 4. Layout and Spacing (layout)

**Impact:** HIGH  
**Description:** Group related elements with proximity, use a consistent spacing scale, and keep alignment predictable.

## 5. Typography (typography)

**Impact:** HIGH  
**Description:** Readable type systems: one sans-serif, two weights, ideal line length and line height, accessible contrast.

## 6. Copywriting (copy)

**Impact:** MEDIUM-HIGH  
**Description:** Interface text that scans well: descriptive headings, bullets, and labels that work out of context.

## 7. Forms (forms)

**Impact:** MEDIUM-HIGH  
**Description:** Labels, hints, and field patterns that reduce errors and completion time.

## 8. Buttons (buttons)

**Impact:** MEDIUM-HIGH  
**Description:** Three button weights, accessible targets, shape contrast, and semantic HTML.
