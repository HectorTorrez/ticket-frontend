## Space by Relationship (Law of Proximity)

**Impact: CRITICAL (spacing communicates structure)**

Spacing between elements should reflect how related they are. Closely related → less space. Unrelated → more space. Think nested rectangles: smallest gaps innermost, largest gaps between major sections.

**Incorrect:**

Same 16px gap between label+input pairs and between unrelated page sections.

**Correct:**

Label to input: 4–8px. Input group to next group: 24px. Section to section: 32–48px+.
