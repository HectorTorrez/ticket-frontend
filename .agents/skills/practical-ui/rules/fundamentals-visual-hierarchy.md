## Create Clear Visual Hierarchy

**Impact: CRITICAL (order of importance drives comprehension)**

Not all information is equally important. Make primary content and actions more prominent using size, weight, colour, contrast, spacing, position, and depth.

**Incorrect:**

Multiple elements with equal visual weight competing for attention. Primary CTA with low contrast, same size as secondary text.

**Correct:**

One clear primary action (high contrast, bold). Headings larger/bolder than body. Supporting metadata in lighter grey. Related groups nested visually.
