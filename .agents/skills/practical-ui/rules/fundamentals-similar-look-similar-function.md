## Similar Look, Similar Function

**Impact: CRITICAL (avoids misleading interactive cues)**

If elements look similar, users expect them to work the same way. Non-interactive content must not use button or link styling.

**Incorrect:**

Stat blocks styled with filled brand-colour backgrounds like primary buttons. Decorative icons in pill containers that look tappable.

**Correct:**

Reserve filled brand colour and button chrome for real actions. Display stats with neutral typography. Use plain icons or lower-contrast treatment for decorative/non-interactive icons.
