## Prefer Tall X-Height Typefaces

**Impact: MEDIUM (lowercase letter height affects readability)**

Choose typefaces with taller lowercase letters (x-height) and comfortable letter spacing for UI sizes. "Text type" families excel at small sizes; verify at 12–16px before committing.

**Incorrect:**

Display typeface with short x-height used for 14px form labels—hard to read.

**Correct:**

UI-oriented sans (Inter, Source Sans, etc.) with generous x-height. Test body and label sizes in context.
