## Use Common Design Patterns

**Impact: HIGH (familiar beats novel for core flows)**

Stick with conventions users already know: underlined links, top navigation, labels above fields, primary button on the right in dialogs (platform-dependent but be consistent). Innovate in branding, not in basic control behavior.

**Incorrect:**

Reinventing tab behavior, hiding standard controls, or using unconventional gestures for common tasks without strong reason.

**Correct:**

Standard patterns for navigation, forms, and dialogs. Document deviations when you must break convention and mitigate with labels or onboarding.

Reference: [Practical UI](https://www.practical-ui.com/)
