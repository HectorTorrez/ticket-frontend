## Group Related Elements

**Impact: CRITICAL (structure reduces cognitive load)**

Break information into related groups using four methods (strongest to subtle):

1. Same container
2. Proximity (closer spacing)
3. Similar appearance
4. Continuous alignment

Combine methods when helpful; prefer spacing over boxes when possible.

**Incorrect:**

Uniform tight spacing everywhere so sections blur together. Every group wrapped in a bordered card.

**Correct:**

Tight spacing within a group (8–16px). Larger gaps between unrelated groups (24–48px). Containers only when other cues aren't enough.
