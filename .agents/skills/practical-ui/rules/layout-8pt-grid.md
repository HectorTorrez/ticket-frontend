## Align to an 8pt Grid

**Impact: HIGH (consistent alignment across breakpoints)**

Size and space elements in multiples of 8px (4px where finer control is needed). Layout grids, component heights, and padding should snap to the grid—especially button heights (48px = 6×8).

**Incorrect:**

Button height 43px, section padding 25px, misaligned baselines across columns.

**Correct:**

48px min button height, 16/24/32px padding tokens, column gutters on 8px multiples.

Reference: [Practical UI design system](https://www.practical-ui.com/)
