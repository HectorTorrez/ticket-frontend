## Limit Uppercase Text

**Impact: MEDIUM (ALL CAPS is slower to read)**

Readers recognize words by shape; uppercase removes shape variation. Use sentence case for labels and headings. Reserve uppercase for very short badges if needed.

**Incorrect:**

`LOCATION` `PRICE PER NIGHT` in uppercase metadata labels.

**Correct:**

Sentence case: "Location", "Price per night". Title case for headings if brand requires—avoid long uppercase strings.
