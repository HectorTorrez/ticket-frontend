## Ensure UI Element Contrast ≥ 3:1

**Impact: CRITICAL (users must see control boundaries)**

Form fields, buttons, icons, and focus indicators need at least **3:1** contrast against adjacent colours so shape and state are visible—not just decorative fills.

**Incorrect:**

Ghost button with 2:1 border on white. Icon on photo with no backing. Input border barely visible against background.

**Correct:**

Button borders/fills ≥3:1. Icons on variable backgrounds: solid circular/square backing. Input borders clearly visible (3:1 minimum).
