## Be Consistent

**Impact: CRITICAL (predictable interfaces are faster to use)**

Similar elements should look and behave similarly—within your product and compared to established patterns (e.g. filled icon = selected, outlined = default).

**Incorrect:**

Mixing filled and outline icons randomly; rounded corners on buttons but sharp corners on cards; different hover patterns for the same control type.

**Correct:**

One icon style (e.g. 2px stroke, rounded caps). One corner radius scale. One interaction pattern per component type. Add text labels to icons when meaning isn't universal.
