## Use a Single Sans-Serif Typeface

**Impact: HIGH (serif/display faces hurt small UI text)**

One sans-serif family for the entire interface. Sans serifs are neutral, legible at small sizes, and familiar in apps. Avoid decorative serif headings in dense product UI unless brand requires it—and still prioritize readability.

**Incorrect:**

Serif display font for headings, geometric sans for body, monospace for labels—three families fighting.

**Correct:**

One family (e.g. Inter, system-ui stack). Differentiate with size and weight only.
