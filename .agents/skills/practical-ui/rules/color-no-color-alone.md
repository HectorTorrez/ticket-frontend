## Don't Rely on Colour Alone

**Impact: CRITICAL (~8% of men have colour vision deficiency)**

Never use colour as the only indicator of meaning, state, or interactivity. Add underlines, icons, fills, borders, or labels.

**Incorrect:**

Links styled as blue text with no underline; selected tab indicated only by subtle colour shift.

**Correct:**

Underline links (or bold + icon). Selected tab: underline and/or filled icon. Error states: icon + text, not red border alone.
