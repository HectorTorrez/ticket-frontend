## Balance Icon and Text Pairs

**Impact: MEDIUM (visual prominence should match)**

When icons sit beside text, they should feel equally prominent. Match size/thickness where possible. If icons are heavier, lower icon contrast—not below 3:1 for interactive icons—or darken text to ≥4.5:1.

**Incorrect:**

Bold 24px icons with light 12px grey labels—icons dominate; text fails contrast.

**Correct:**

Icon ~20–24px aligned to cap height. Text regular weight, ≥4.5:1. Similar visual weight.
