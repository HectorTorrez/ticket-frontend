## Avoid Unnecessary Containers

**Impact: HIGH (containers add clutter when grouping is already clear)**

Containers are the strongest grouping cue but add visual weight. If proximity, alignment, or similarity already group items, remove the box.

**Incorrect:**

Each list item in its own bordered card when spacing and alignment already separate rows.

**Correct:**

Remove redundant borders; rely on spacing and alignment. Add containers only when groups would otherwise be ambiguous.
