## Use One Primary Button Per View

**Impact: HIGH (multiple primaries compete for attention)**

Highlight the single most important action with a primary button. If no action dominates, use secondary/tertiary for all actions instead of multiple primaries.

**Incorrect:**

"Save", "Publish", and "Continue" all styled as solid brand buttons on one form.

**Correct:**

One primary ("Save changes"). Others secondary ("Cancel") or tertiary ("Delete account").
