## Reserve Brand Colour for Interactive Elements

**Impact: HIGH (consistent affordance learning)**

Apply brand colour to text links and primary buttons so users learn what's interactive. Some elements (underlined text, card affordances) may stay neutral if other cues exist.

**Incorrect:**

Blue section titles, blue metadata, and blue buttons—all the same treatment.

**Correct:**

Interactive: brand colour + underline for links; filled brand for primary buttons. Non-interactive: neutral greys.
