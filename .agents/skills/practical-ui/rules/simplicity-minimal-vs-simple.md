## Don't Confuse Minimalism with Simplicity

**Impact: HIGH (fewer pixels ≠ easier to use)**

Minimal interfaces remove elements; simple interfaces are easy to understand. Hiding labels or actions for aesthetics creates ambiguity.

**Incorrect:**

Icon-only bottom navigation with no text labels. Critical actions only in a "⋯" menu when space allows visible buttons.

**Correct:**

Add text labels to icons (especially nav). Show important actions inline when there's room. Minimal look with complete information.
