## Avoid Disabled-Looking Grey Buttons

**Impact: MEDIUM (light grey reads as unavailable)**

Light grey filled buttons resemble disabled states. Use clear secondary styling (outline or text) instead of pale fills.

**Incorrect:**

Secondary action as low-contrast light grey fill with grey text—looks inactive.

**Correct:**

Secondary: outline with ≥3:1 border contrast, or text button with underline/weight. Disabled state: explicitly styled and non-interactive (`disabled` attribute).

Reference: [Button design tips](https://www.adhamdannaway.com/blog/ui-design/button-design-tips)
