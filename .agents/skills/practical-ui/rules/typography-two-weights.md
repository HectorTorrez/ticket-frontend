## Use Regular and Bold Weights Only

**Impact: HIGH (extra weights add noise)**

Limit UI to **regular (400)** and **bold (600–700)**. Semi-bold is acceptable if bold feels too heavy. Avoid light/thin/extra-light for small text—even with sufficient contrast, thin strokes are hard to read.

**Incorrect:**

Light location text, extra-light metadata, medium subheads, bold titles—four weights in one card.

**Correct:**

Bold headings, regular body and labels. Reserve thin weights for large display only if ever needed.
