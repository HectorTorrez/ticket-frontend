## Use Colour Purposefully

**Impact: HIGH (decorative colour confuses interactivity)**

Use colour sparingly. Start from neutral greyscale; add colour where it adds meaning—typically interactivity or semantic status.

**Incorrect:**

Brand blue on headings, star ratings, and decorative icons while also using it for links—everything looks clickable.

**Correct:**

Neutral typography for content. Brand/accent colour on links, primary buttons, and selected states only.
